# 段取りかんたん手順書

現場ではスマホで工程順に写真を撮りため、あとから PC で順番・文章・書き込み（矢印／赤丸／赤枠／文字）を仕上げ、A4 の「写真つき作業手順書」として印刷・PDF 保存できるアプリです。

- 写真・文章・手順書は、**この端末のブラウザの中（IndexedDB）だけ**に保存します。外部のサーバーや AI には一切送りません（外部への通信 0 件）。
- 受け渡しは、スマホで書き出した **1つの .json ファイル**（写真・順番・メモをまとめたもの）を、PC で読み込む形です。

## 4つの画面
1. **現場で撮る（スマホ）**：カメラ撮影または写真選択で、STEP 1, 2, … と工程順に追加。仮タイトルと一言メモを入れ、「PCへ渡すファイルを書き出す」で .json をダウンロード。
2. **1ステップ確認（スマホ）**：大きな写真＋短い手順＋注意点を、1ステップずつめくって確認（左右になぞっても進む）。
3. **机で仕上げ（PC）**：.json をファイル選択／ドラッグ＆ドロップで読み込み。工程の入れ替え（ドラッグ／↑↓）、作業内容・注意点・使用工具の文章仕上げ、写真への書き込み（1つ戻す・やり直しつき）。
4. **A4で印刷（PC）**：A4・縦の印刷レイアウトをそのまま表示し、印刷／PDF 保存。

## 見本データ
実在の会社・製品・品番・図面・個人情報は使っていません。完全に架空の「治具の清掃とワークセット手順」（写真は、画面上で描いたイラスト）が入っています。

## 動かし方
```
npm install
npm run dev          # 開発用（http://localhost:5194）
npm run build:pages  # 公開用（docs フォルダに出力）
```

## 限り（できていないこと）
- 複数人での同時編集や、サーバーでの共有はありません（ファイルでの受け渡しのみ）。
- 実機のスマホ（iPhone・Android）のカメラでの撮影は、これから確かめます。
- 写真は幅 1280px の JPEG に縮めて保存します（元の大きさのままではありません）。
